## Why

Сайт Кречевиц рассказывает об истории места через географию, фото, истории и аэродром, но не выделяет людей, связанных с посёлком. Раздел «Известные люди» даёт отдельное место для биографий и контекста — рядом с уже существующими разделами.

## What Changes

- Новый раздел сайта «Известные люди» с маршрутом `/people`
- Список людей и отдельная страница на каждого
- Контент в markdown (как у «Историй» и «Аэродрома»)
- Пункт меню «Известные люди»
- Несколько стартовых записей, чтобы раздел не был пустым

## Capabilities

### New Capabilities
- `notable-people`: список и карточки известных людей Кречевиц (контент, навигация, маршруты)

## Impact

- Новые страницы: `pages/people/index.jsx`, `pages/people/[slug].jsx`
- Новые данные: `data/people/*.md`
- Меню: `components/Menu/Menu.jsx`
- Переиспользуются существующие `lib/getAllFilesIds`, `lib/parseMarkdownFile`, `layouts/PageLayout`
- Новых зависимостей не требуется
- Статические экспорт и GitHub Pages без изменений в CI
